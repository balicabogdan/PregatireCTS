Se dezvoltă o aplicație software destinată gestionării unei platforme de livrare cu roboți autonomi

3p. În sistem există mai multe tipuri de roboți de livrare preconfigurați, folosiți frecvent pentru inițializarea rapidă a unor unități noi. Un robot este reprezentat printr-un obiect de tip DeliveryRobot și conține informații precum: model, capacitate de transport, autonomie, viteză maximă, tip de senzori și set de rute standard. Deoarece definirea completă a unui robot de la zero consumă timp din cauza setului de rute standard, se cere implementarea unui mecanism prin care anumite modele să poată fi reutilizate. Obiectele nou create ulterior pot fi particularizate prin modificarea atributelor.

1.5p. Să se testeze soluția prin:

definirea a cel puțin 2 prototipuri diferite de roboți;

clonarea unuia dintre prototipuri de cel puțin 2 ori;

particularizarea unei clone;

demonstrarea faptului că prototipul inițial rămâne nemodificat.

3p. Fiecare robot poate fi echipat cu un pachet de baterii de tip RobotBatteryPack. Un pachet trebuie să conțină elemente obligatorii precum: batteryName, capacity și voltage. În plus, utilizatorul poate selecta opțional diferite caracteristici precum: fastChargeSupport, coolingSystem, shockProtection, wirelessMonitor sau extendedWarranty. Deoarece nu toate pachetele folosesc aceleași opțiuni suplimentare, se cere implementarea unui mecanism flexibil de construire a obiectelor de tip RobotBatteryPack.

1.5p. Să se testeze soluția prin:

crearea a cel puțin 3 pachete diferite;

un pachet configurat minimal;

un pachet cu exact 2 opțiuni suplimentare;

un pachet cu numărul maxim permis de opțiuni suplimentare.

public interface IDeliveryRobot {
    String getModel();
    float getTransportCapacity();

    float getMaxSpeed();

    void setTransportCapacity(float capacity);
